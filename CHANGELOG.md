# Changelog

## 0.1.0

- Public AcaCite system release.
- Retrieval-only MCP surface for agent clients.
- Provenance-backed HTTP ingestion, search, source resolution, and optional local answer generation.
- Citation expansion through local references, Crossref, and OpenAlex, with optional open-access PDF download.
- Public tree audit, unit tests, integration tests, and example systemd user services.
